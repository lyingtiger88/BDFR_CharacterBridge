# Third-party architecture references

BDFR Body Authoring was designed with reference to the following public Daz 3D repositories:

- `daz3d/DazBridgeUtils` — Apache License 2.0
- `daz3d/DazToUnreal` — Apache License 2.0

No source files from those repositories are vendored in this native milestone. Their public architecture and documented APIs informed the separation between native dialogs/actions, bridge metadata and QA scripting.

If future versions vendor or modify Apache-licensed source, retain the corresponding LICENSE/NOTICE and modification notices required by Apache-2.0.
